## 一、30 秒上手（第一次使用按顺序做）

1. **打开库**：Obsidian → 「打开其他库」→ 「打开文件夹作为库」→ 选择本文件夹。
2. **启用核心插件**：设置 → 核心插件 → 打开 `模板`、`日记`、`书签`、`大纲`。
   - `模板` 文件夹已指向 `06-模板`，`日记` 已指向 `03-日报`，无需再改。
3. **装 2 个社区插件**（社区插件 → 浏览 → 安装 → 启用）：
   - **Dataview**：让 [首页](/posts/notes-index)、[课程索引](/posts/notes-index)、[知识索引](/posts/notes-index)、[学科分类](/posts/notes-index) 里的表格自动更新。**必装。**
   - **Templater**：让「新建课程笔记」自动填今天日期和课程名（可选，见第五节）。
   - 装完两个插件后，本库即可 100% 运行。
4. **建第一门课**：打开 [课程索引](/posts/notes-index) → 按里面的「新建课程」步骤，30 秒建好一门课。
5. **开始记**：打开 [录入工作流](/posts/photo-to-learning-notes)。笔记或作业照片可直接发到当前对话，按「照片协作流程」整理、批改并回写笔记。

## 二、目录结构（每个文件夹只干一件事）

| 文件夹 | 放什么 | 什么时候放 |
| --- | --- | --- |
| `00-收集箱` | 未归类的碎片：临时想法、还没整理的照片文字 | 随手记，每周清空一次 |
| `01-课程库` | 每门课一个文件夹，内含「课程名.md」总览 + 章节/主题笔记 | 上课时 |
| `02-知识库` | 一个知识点 = 一篇笔记，文件名就是知识点名 | 复习、做题、看资料时 |
| `03-日报` | 每日记录、疑问、第二天要问老师的问题 | 每天 2 分钟 |
| `04-资料库` | 教材、课件、真题、**培养方案** | 拿到资料时 |
| `05-附件` | 所有图片、PDF、录音（**别手动搬动**） | 自动 |
| `06-模板` | 笔记模板 | 不用管 |
| `99-归档` | 学完/过期的内容 | 学期末 |

**两条铁律**

1. **图片只从 `05-附件` 走**：截图/照片拖进笔记时，Obsidian 会自动复制到 `05-附件`，笔记里只留引用。这样换电脑、传网盘都不会丢图。
2. **文件名用中文、不加日期前缀**：日期写在 frontmatter 里（笔记最上方 `---` 之间的属性）。靠属性搜索比靠文件名可靠得多。

## 三、双轨怎么运作（这是整套方案的核心）

```
课堂上一节课  ──►  01-课程库/测绘学概论/测绘学概论.md   （课堂记录，按时间/章节走）
                                    │
                            用 [[双链]] 挑出知识点
                                    ▼
                        02-知识库/水准测量.md          （一个知识点一篇，永久复用）
                                    │
                            期末复习从这里导出
                                    ▼
                        [[知识索引]] / [[作业与考试中心]]
```

- **课程笔记回答「这节课讲了什么」**——有顺序、有老师原话、有板书照片。
- **知识点笔记回答「这个知识点是什么」**——跨课程复用。比如「误差传播定律」同时服务测量学和大物实验，只写一次，两边都链过去。
- 判断标准：**如果一句话明年还会用到，它就该是知识点笔记；如果只跟本周这节课有关，留在课程笔记里。**

## 四、录入路线（对应你的两个需求）

| 场景 | 做法 | 详见 |
| --- | --- | --- |
| 打字录入 | `Ctrl+N` 建笔记 → `Ctrl+T` 插模板 | [录入工作流](/posts/photo-to-learning-notes) 第 1 节 |
| 高数/英语笔记或作业照片 | 当前对话上传 → 识读/整理/批改 → 回写课程或知识点笔记 | [录入工作流](/posts/photo-to-learning-notes)「直接把笔记或作业照片发给我」 |
| 自行处理的板书/课件照片 | 手机拍 → `00-收集箱` → OCR + 图片归档 | [录入工作流](/posts/photo-to-learning-notes) 第 ② 节 |
| 板书/公式 | 拍照存图 + Mathpix/识图取 LaTeX，公式用 `$...$` | [录入工作流](/posts/photo-to-learning-notes) 第 3 节 |
| 课表/PPT 截图 | 同上，重命名为 `YYYYMMDD-主题` | [录入工作流](/posts/photo-to-learning-notes) 第 2 节 |

关键认知：**照片是证据，文字才是能搜索、能复习的资产。** 直接发给我处理时，会先在对话里展示识读/整理结果，再把可确认的文字整理进课程笔记或知识点笔记。看不清的内容会标出来询问，不猜写。

## 五、插件清单（按需，不装也能用）

| 插件 | 作用 | 优先级 |
| --- | --- | --- |
| Dataview | 首页/索引的自动汇总表 | **必装** |
| Templater | 新建笔记自动填日期、课程名 | 推荐 |
| QuickAdd | 一键抓取到收集箱 | 可选 |
| Excalidraw | 手绘示意图、控制网草图 | 测绘很推荐 |
| Obsidian Git | 本地 Git 版本管理，误删可回溯 | 可选（见第七节） |

启用 Templater 后，把 `06-模板/1-课程笔记模板.md` 顶部两行（标注了 `Templater` 的）替换成：

```
<%* const c = await tp.system.prompt("课程名称"); %>
---
type: 课程笔记
course: <% c %>
date: <% tp.date.now("YYYY-MM-DD") %>
---
```

以后用命令面板 `Templater: Create new note from template` 建笔记，课程名和日期就不用敲了。

## 六、每周 10 分钟维护（防止库变垃圾场）

每周日晚上做四件事：

1. 打开 `00-收集箱`，每篇碎片判断归属 → 移动到课程库/知识库，或删掉。
2. 打开 [知识索引](/posts/notes-index)，把「状态: 待整理」的知识点笔记补完（至少写清定义 + 一个例子）。
3. 打开 [作业与考试中心](/posts/notes-index)，更新作业状态和疑问清单。
4. `Ctrl+P` → 「文件恢复: 查看快照」确认没有误删（Obsidian 自带，默认 5 分钟内可恢复）。

## 七、备份（你选了「自己拷网盘」）

**手动方案（够用）**：每周把整个库文件夹 `笔记整理` 复制到网盘同步目录或 U 盘。
- 拷之前先关闭 Obsidian，避免复制到写了一半的文件。
- 整个库包括 `.obsidian` 文件夹一起拷，这样插件、主题、设置一起走。

**升级方案（推荐有空再做）**：直接用网盘同步这个库文件夹。
- OneDrive / 坚果云都可以，但**必须只在关闭 Obsidian 后同步**，或者两端不同时编辑同一篇，否则会产生「冲突副本」文件。
- 手机端若也想同步：用 **Obsidian 移动版 + 坚果云 WebDAV（Remotely Save 插件）** 或 **Syncthing**，别用 OneDrive 同步（手机端体验差）。

**版本回溯方案**：装 Obsidian Git 插件，库初始化为 Git 仓库，每天自动 commit。误删笔记能恢复到任意历史版本，但注意**别把 `.obsidian/workspace.json` 同步到多设备**。

## 八、快速参考

| 想做的事 | 操作 |
| --- | --- |
| 新建笔记 | `Ctrl+N` |
| 插入模板 | `Ctrl+P` → 「模板: 插入模板」 |
| 今天的日报 | 左侧「打开今日日记」图标 |
| 全局搜索 | `Ctrl+Shift+F` |
| 快速切换笔记 | `Ctrl+O` |
| 搜索某个属性 | 搜索框输入 `[status:待整理]` |
| 插入公式 | `$公式$`（行内）或 `$$公式$$`（独立一行） |
| 图片缩放 | `400` |
| 建双链 | 输入 `[[` 后打字 |

**笔记属性（frontmatter）速查**——**直接整段复制**到新笔记最上方（含 `---` 三横线）：

```yaml
---
type: 知识点
course: 测绘学概论
subject: 专业核心
chapter: 第2章
tags: [测绘, 水准测量]
date: 2026-02-19
status: 已掌握
importance: 高
source: 教材第45页
---
```

各字段的取值（**只能是这些值，Dataview 靠精确匹配统计**）：

| 字段 | 允许的取值 |
| --- | --- |
| `type` | `课程` / `课程笔记` / `知识点` / `日报` / `作业` / `摘录` |
| `subject` | `通识基础` / `通识拓展` / `学科平台` / `专业核心` / `个性化发展` / `集中实践` |
| `status` | `待整理` / `学习中` / `已掌握` / `已整理` / `进行中` / `未开始` / `已完成` |
| `importance` | `高` / `中` / `低` |

> ⚠️ **属性值后面不要写 `#` 注释**。YAML 会把 `#` 之后整段吃掉，导致 `status` 变成空值、查询全部失效。要备注就写到正文里。

> `subject` 是**学科分类**，决定这门课/这个知识点出现在 [学科分类](/posts/notes-index) 的哪一组。
> **分类靠属性、不靠文件夹**——文件夹一门课一个（唯一归宿），学科、重要度、掌握度都是属性，这样一个笔记能同时按多个维度筛。

## 九、常见坑

| 现象 | 原因 / 解决 |
| --- | --- |
| Dataview 代码块显示成一堆代码 | 插件没装或没启用 |
| 拖进来的图找不到 | 附件目录被改过；恢复 `05-附件` 设置（设置 → 文件与链接 → 附件默认位置） |
| 手机上打不开库 | 手机端需要把整个文件夹同步过去，不能只同步 `.md` |
| 中文文件名搜索不到 | 搜索时加引号：`"水准测量"`，或直接 `Ctrl+O` 按文件名跳转 |
| 同步后出现「xxx (冲突副本)」 | 两端同时编辑同一篇；以时间较新的一份为准，手动合并后删掉副本 |
