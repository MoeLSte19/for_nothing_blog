## 📋 本节要点

1. 函数的**图形**是一个点集 $C=\{(x,y)\mid y=f(x),\ x\in D\}$
2. **三种表示法**：表格法（便于查值）、图形法（直观）、解析法（便于运算）
3. 解析法分**显函数 / 隐函数 / 分段函数**三种
4. **四种特性**：有界性、单调性、奇偶性、周期性
5. ★ 老师补充：单值/多值函数、无界量 vs 无穷大量、奇偶速算、周期伸缩法则

## 📝 课堂记录（老师强调与补充）

> 以下都是**教材上没有**的内容，价值最高。

### ① 单值函数与多值函数

- 圆方程 $x^2+y^2=a^2$ 是**多值**对应：一个 $x$ 对应两个 $y$
- **高数只研究单值函数**，多值必须限定范围转成单值（如取 $y\geq0$ 得上半圆）
- `!!` 这是**概念辨析考点** → [单值函数与多值函数](/posts/single-and-multivalued-functions)

### ② 无界量 ≠ 无穷大量

- 反例 $y = \dfrac1x\sin\dfrac1x$（$x\to0$）
- **无界**：振幅能冲到任意大（取 $\sin$ 取到 1 的那些点）
- **不是无穷大**：正弦周期性回到 0，不满足"从某点起恒大于界"
- `!!` 老师说是**概念判断题和选择题必考陷阱** → [无界量与无穷大量](/posts/unbounded-and-infinite-quantities)

### ③ 奇偶性速算

- `!!` 口诀：**奇 + 偶 = 非奇非偶**；**奇 × 奇 = 偶**
- 典型对数型奇函数：$f(x)=\ln\!\left(x+\sqrt{1+x^2}\right)$
- 速判技巧：**乘共轭因式**，$(\sqrt{1+x^2}-x)(\sqrt{1+x^2}+x)=1$，得 $f(-x)+f(x)=\ln 1=0$
- `!!` 老师说这是**期末填空题的速算模板** → 已并入 [函数的四种特性](/posts/four-properties-of-functions)

### ④ 复合周期的伸缩法则

- 若 $f(x)$ 周期为 $T$，则 $f(ax+b)$ 周期为 $\dfrac{T}{\lvert a\rvert}$
- ⚠️ 只看 $x$ 的系数，与常数项无关
- `!!` 老师说这是**大题计算周期和求分段反函数的核心方法** → 已并入 [函数的四种特性](/posts/four-properties-of-functions)

### ⑤ 课堂补充题（老师**额外布置**的例题）

$$f(x) = \sqrt{\frac{x^2(x-4)}{(x^2-1)(9-x^2)}}$$

- 求定义域，**答案：$(-\infty,-3)\cup(-1,1)\cup(3,4]$**
- ⚠️ **第一要害是根号的范围**：整个分式在**一个**大根号里
  - 分母在根号内 ⟹ **可以为负**（负负得正也满足 $\geq0$），只需 $\neq0$
  - 我之前按"分子分母各一个根号"算，得出空集——**读错式子**
- 关键点：分母零点 $x=\pm1,\pm3$ 排除；孤立点 $x=0$、$x=4$ 保留
- `!!` 老师说这是**考试高频压轴题型**
- → 完整解法：[求定义域常用的不等式解法](/posts/inequalities-for-function-domains)
- 完整解法 → [求定义域常用的不等式解法](/posts/inequalities-for-function-domains)

## 🧮 例题（含老师指出的我的错因）

### 例 1.1.2 求定义域（教材 P6）

$$f(x) = \frac{\ln(3-x)}{\sin x} + \sqrt{5+4x-x^2}, \qquad D = \{x \mid -1 \leq x < 3,\ x \neq 0\}$$

**`!!` 老师指出的错因**（我草稿上的问题）：

> 我在草稿上写了 `x < -1` 和 `x >= 3` —— **这是把「交集（AND）」和「补集/向外取」记混了。**

**为什么会这样**：
- 如果解的是 $x^2-4x-5 \geq 0$，两根**在两边**，解集才是 $x\leq-1$ 或 $x\geq5$
- 但本题是 $-x^2+4x+5\geq0$，**移项变号后是 $\leq 0$**，两根**在内侧**，取 $-1\leq x\leq5$
- 取交集：$[-1,5]\cap(-\infty,3) = [-1,3)$
- **绝对不能取 $x\geq3$**：此时真数 $3-x\leq0$，对数无意义

**我的检查清单**（下次做题照这个走）：
1. 二次项系数是正的吗？不是就先移项变号 ⚠️
2. 所有条件都取**交集**了吗？能画数轴吗
3. 分母的根取到了吗（不能取）
4. 有孤立点吗（单独验证）
5. 端点开闭对吗

→ 完整的解法整理在 [求定义域常用的不等式解法](/posts/inequalities-for-function-domains)

### 例 1.1.3 判断同一函数（教材 P6）

| 组 | 结论 | 理由 |
| --- | --- | --- |
| $f(x)=\lvert x\rvert$ 与 $g(x)=\sqrt{x^2}$ | **是**同一函数 | 定义域都是 $\mathbb{R}$，且 $\sqrt{x^2}=\lvert x\rvert$ |
| $f(x)=\dfrac{x}{x}$ 与 $g(x)=1$ | **不是** | 定义域不同（前者 $x\neq0$） |

> ⚠️ 顺序永远是**先比定义域**。
