> 一句话：**自然定义域就是让数学式有意义的一切实数**，求它 = 列出所有"雷区"条件，然后**取交集**。

## 1. 定义 / 核心结论

| 概念 | 含义 |
| --- | --- |
| **实际定义域** | 按问题的实际意义确定（如圆面积 $S=\pi r^2$ 中 $r>0$） |
| **自然定义域** | 不考虑实际意义，只要求数学式有意义 |

**三大雷区（必须倒背）**：

| 结构 | 条件 |
| --- | --- |
| 分式 $\dfrac{1}{g(x)}$ | $g(x) \neq 0$ |
| 偶次根式 $\sqrt[2n]{g(x)}$ | $g(x) \geq 0$ |
| 对数 $\log_a g(x)$ | $g(x) > 0$（且 $a>0,\ a\neq 1$） |

补充（后面才会遇到，先记着）：$\arcsin g(x)$、$\arccos g(x)$ 要求 $\lvert g(x) \rvert \leq 1$；$\tan g(x)$ 要求 $g(x) \neq \frac{\pi}{2}+k\pi$。

> 🚨 **我的错题（2026-09-14）**：习题 1.1 第 **2(4)** 题 $y=\arcsin\frac1x+\arctan 2x$ 我做空白，
> 因为不知道反三角函数的定义域限制。**这不是 1.1.2 的内容，而是「预备知识」的知识缺口** →
> 已单独整理为 [反三角函数的定义域与值域](/posts/inverse-trigonometric-functions)。
> 要点：$\arcsin$/$\arccos$ 要求 $\lvert u \rvert \leq 1$，而 **$\arctan$/$\operatorname{arccot}$ 对一切实数都有定义**。

## 2. 关键公式

$$
\text{定义域} = \bigcap_{i} \{x \mid \text{第 } i \text{ 个雷区条件成立}\}
$$

> 白话：**每个雷区各给一个不等式，全部同时满足（取交集）**。最后把被排斥的孤立点挖掉。

## 3. 解题步骤

1. 找出解析式里**每一个**"雷区"结构（分式、偶次根、对数）
2. 每个雷区写一个不等式（或不等式组）
3. **解不等式组，取交集**
4. 检查是否有需要**挖掉的散点**（如 $\sin x \neq 0$ 排除 $x=n\pi$）
5. 用**区间或集合**写出最终答案

## 4. 典型例题

**例 1（教材例 1.1.2）**：求 $f(x) = \dfrac{\ln(3-x)}{\sin x} + \sqrt{5+4x-x^2}$ 的定义域。

- **雷区识别**：$\ln(3-x)$ 是对数 → $3-x>0$；$\sin x$ 在分母 → $\sin x \neq 0$；$\sqrt{5+4x-x^2}$ 是偶次根 → $5+4x-x^2 \geq 0$

$$
\begin{cases}
3-x > 0 \\
\sin x \neq 0 \\
5+4x-x^2 \geq 0
\end{cases}
\Longrightarrow
\begin{cases}
x < 3 \\
x \neq n\pi\ (n \in \mathbb{Z}) \\
-1 \leq x \leq 5
\end{cases}
$$

- **取交集**：$[-1,5] \cap (-\infty,3) = [-1,3)$，再挖掉其中的 $x = n\pi$。
  在 $[-1,3)$ 内的 $n\pi$ 有 $0,\ \pi$（$-\pi \approx -3.14$ 不在内，$2\pi \approx 6.28$ 不在内）
- **答案**：$D = \{x \mid -1 \leq x < 3,\ \text{且}\ x \neq 0\}$
  （严格写应排除 $\pi$，教材此处按惯例只列了 $x\neq 0$，注意老师课上怎么处理）

> ⚠️ **易错点**：$5+4x-x^2 \geq 0$ 化成 $x^2-4x-5 \leq 0$，即 $(x-5)(x+1) \leq 0$，得 $-1 \leq x \leq 5$。
> **符号方向容易搞反**，这是本题最常见的错。

**例 2**：求 $y = \sqrt{1-x^2}$ 与 $y = \dfrac{1}{\sqrt{1-x^2}}$ 的自然定义域。

- $y=\sqrt{1-x^2}$：$1-x^2 \geq 0 \Rightarrow x \in [-1,1]$
- $y=\dfrac{1}{\sqrt{1-x^2}}$：既要 $1-x^2 \geq 0$，又要 $\sqrt{1-x^2} \neq 0$（分母不为零）$\Rightarrow x \in (-1,1)$

> 🔑 **同一个根式在分母上，端点就要挖掉**——这是高频陷阱。

## 5. 易错与坑

- ⚠️ 忘记**取交集**，把各条件的解简单并列
- ⚠️ 根式在**分母**时忘记端点不取（$[-1,1]$ 变成 $(-1,1)$）
- ⚠️ $5+4x-x^2\geq0$ 这类**二次不等式方向搞反**
- ⚠️ 忘记**挖散点**（$\sin x \neq 0$、$\tan x$ 的排斥点）
- ⚠️ 定义域要写成**集合或区间**，不能只写一个不等式
- 🚨 **忽略反三角函数的限制**（我的 2(4) 题错因）：$\arcsin$、$\arccos$ 要求 $\lvert u\rvert\leq1$；但 **$\arctan$ 无限制，不要多写条件**

## 8. 我的理解

求定义域这件事，本质是**把解析式里所有"不允许"的地方翻译成不等式，再求同时成立的区域**。它不难，但极容易因为漏一个雷区或搞反不等号而全错——所以做完一定要**回头逐项检查每个雷区都写到了**。
