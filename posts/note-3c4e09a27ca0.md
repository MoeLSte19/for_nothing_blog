## 1. 函数的定义

**定义 1.1.1**：设 $x$ 和 $y$ 是两个变量，$D$ 是一个给定的非空数集。若存在对应法则 $f$，使得当变量 $x$ 在其变化范围 $D$ 内任意取定一个数值时，变量 $y$ 按照对应法则 $f$ 总会取到唯一确定的数值和 $x$ 对应，则称 $f$ 是定义在 $D$ 上的函数，记为

$$y = f(x), \quad x \in D$$

| 符号 | 名称 | 说明 |
| --- | --- | --- |
| $x$ | 自变量 | |
| $y$ | 因变量 | 由 $x$ 唯一确定 |
| $D$ | **定义域** | $D = D_f$ |
| $R_f = f(D)$ | **值域** | $R_f = \{f(x) \mid x \in D\}$ |
| $f(x_0)$ | 函数值 | $x_0 \in D$ 时对应 $y_0$ |

**两个基本要素：定义域 $D$ + 对应法则 $f$。** 两者都相同才是同一个函数。

### 记法要点

- 函数符号**可以任意选取**：$f,\ g,\ \varphi,\ \psi,\ F$ 都行。
- 也常用**因变量符号**直接表示函数：$y = y(x)$、$S = S(r)$。

## 2. 定义域的两种确定方式

| 方式 | 含义 | 例子 |
| --- | --- | --- |
| **有实际背景** | 按实际意义确定 | 圆面积 $S = \pi r^2$，$r$ 是半径，故 $r > 0$ |
| **抽象数学式（自然定义域）** | 使数学式**有意义**的一切实数 | $y = \sqrt{1-x^2}$ 的自然定义域是 $[-1,1]$；$y = \dfrac{1}{\sqrt{1-x^2}}$ 是 $(-1,1)$ |

### 求自然定义域的三条固定套路

$$\text{分母} \neq 0 \qquad \text{偶次根号下} \geq 0 \qquad \text{对数的真数} > 0$$

### 教材例 1.1.2

求 $f(x) = \dfrac{\ln(3-x)}{\sin x} + \sqrt{5+4x-x^2}$ 的定义域。

**解**：要使 $f(x)$ 有意义，必须

$$
\begin{cases}
3-x > 0, \\
\sin x \neq 0, \\
5+4x-x^2 \geq 0
\end{cases}
\quad\Longrightarrow\quad
\begin{cases}
x < 3, \\
x \neq n\pi \ (n \in \mathbb{Z}), \\
-1 \leq x \leq 5
\end{cases}
$$

所以定义域为 $D = \{x \mid -1 \leq x < 3,\ \text{且}\ x \neq 0\}$。

> 💡 三个条件**取交集**，最后一步还要把排斥点（$x = n\pi$ 中落在区间内的）挖掉。

### 教材例 1.1.3（判断两个函数是否相同）

| 题 | 结论 | 理由 |
| --- | --- | --- |
| $f(x) = \lvert x \rvert$ 与 $g(x) = \sqrt{x^2}$ | **是**同一函数 | 定义域都是 $(-\infty, +\infty)$，且 $g(x) = \sqrt{x^2} = \lvert x \rvert$，对应法则也相同 |
| $f(x) = \dfrac{x}{x}$ 与 $g(x) = 1$ | **不是**同一函数 | $f$ 的定义域是 $(-\infty,0) \cup (0,+\infty)$，$g$ 的定义域是 $(-\infty,+\infty)$，**定义域不同** |

> ⚠️ 这是考点：判断同一函数**先比定义域**，定义域不同直接否定，不用再看对应法则。

## 3. 函数的表示法

**三种表示法**：表格法、图形法、解析法。

| 方法 | 做法 | 优点 |
| --- | --- | --- |
| 表格法 | 用列表表示 | 便于**查函数值**（火车时刻表、银行外汇牌价） |
| 图形法 | 描点画图 | **直观**，能一眼看出单调性、奇偶性 |
| 解析法 | 用方程给出 | 便于**运算和推导**，是理论推导的主力 |

### 解析法的三种情形

| 情形 | 特征 | 例子 |
| --- | --- | --- |
| **显函数** | $y$ 由 $x$ 的解析式**直接**表示 | $y = \arctan x + x^2$ |
| **隐函数** | $x$ 与 $y$ 的对应关系由方程 $F(x,y)=0$ 确定 | $xy + \ln y = 1$ |
| **分段函数** | 定义域的不同范围内**有不同解析表达式** | 见下 |

> 📌 **分段函数是一个函数，不是几个函数。** 它的定义域取各段的**并集**。

### 教材例 1.1.4–1.1.7（四个必须记住的分段函数）

**① 符号函数**（例 1.1.4）

$$y = \operatorname{sgn} x =
\begin{cases}
1, & x > 0, \\
0, & x = 0, \\
-1, & x < 0
\end{cases}
\qquad D = (-\infty,+\infty),\quad R_f = \{-1,\,0,\,1\}$$

**② 绝对值函数**（例 1.1.5）

$$y = \lvert x \rvert =
\begin{cases}
x, & x \geq 0, \\
-x, & x < 0
\end{cases}
\qquad D = (-\infty,+\infty),\quad R_f = [0,+\infty)$$

**③ 分段函数**（例 1.1.6）

$$y = f(x) =
\begin{cases}
-x, & x < 0, \\
x^2, & 0 \leq x \leq 1, \\
1, & x > 1
\end{cases}
\qquad D = (-\infty,+\infty)$$

**④ 取整函数**（例 1.1.7）

$$y = [x] = n, \qquad n \leq x < n+1,\quad n \in \mathbb{Z}$$

即 $x$ 是**不超过 $x$ 的最大整数**。例如 $\left[\dfrac{3}{2}\right] = 1$，$[-2.5] = -3$。

$$D = (-\infty,+\infty), \qquad R_f = \mathbb{Z}$$

> ⚠️ 取整函数是**阶梯状**图形，每个整数点处**左闭右开**（画图时注意空心点/实心点）。
> 例：$[-2.5] = -3$ 而不是 $-2$——**取整是向下取，不是四舍五入**。

## 4. 函数的四种特性 ★本节重点

> 这四条是整章的常考点，也是后面判断极限、单调性、凹凸性的工具。

### （1）函数的有界性

设函数 $f(x)$ 的定义域为 $D$，区间 $X \subset D$：

| 概念 | 定义 |
| --- | --- |
| 在 $X$ 上有**上界** | $\exists K_1$，使 $\forall x \in X,\ f(x) \leq K_1$，称 $K_1$ 为**上界** |
| 在 $X$ 上有**下界** | $\exists K_2$，使 $\forall x \in X,\ f(x) \geq K_2$，称 $K_2$ 为**下界** |
| 在 $X$ 上**有界** | $\exists M > 0$，使 $\forall x \in X,\ \lvert f(x) \rvert \leq M$ |
| 在 $X$ 上**无界** | 这样的 $M$ 不存在，即 $\forall M>0$，总 $\exists x_1 \in X$ 使 $\lvert f(x_1) \rvert > M$ |

**教材的两个例子（关键对比）**：

- $f(x) = \sin x$ 在 $(-\infty,+\infty)$ 内**有界** —— 因为 $\forall x \in (-\infty,+\infty)$，恒有 $\lvert \sin x \rvert \leq 1$
- $f(x) = \dfrac{1}{x}$ 在开区间 $(0,1)$ 内**无上界但有下界**，在 $[1,+\infty)$ 内**有界**

> 🔑 **有界性依赖于区间！** 同一个函数在不同区间上，有界性可能完全不同。
> 这是最容易错的一点：问"$f(x)=\frac1x$ 有没有界"必须先问"在哪个区间上"。

### （2）函数的单调性

设 $y = f(x)$ 的定义域为 $D$，区间 $I \subset D$，$\forall x_1, x_2 \in I$ 且 $x_1 < x_2$：

| 条件 | 结论 |
| --- | --- |
| $f(x_1) < f(x_2)$ | $f(x)$ 在 $I$ 上**单调增加** |
| $f(x_1) > f(x_2)$ | $f(x)$ 在 $I$ 上**单调减少** |

单调增加和单调减少统称**单调函数**。

**教材例子**：
- $y = \dfrac{1}{x^2}$ 在 $(-\infty,0)$ 内单调增加，在 $(0,+\infty)$ 内单调减少 ← **分区间讨论**
- $y = x^2$ 在 $(-\infty,0)$ 内单调减少，在 $(0,+\infty)$ 内单调增加；**但在 $(-\infty,+\infty)$ 内不是单调的**

> ⚠️ 说"某函数单调"**必须指明区间**，否则不成立。

### （3）函数的奇偶性

**前提**：定义域 $D$ **关于原点对称**（即 $\forall x \in D$，有 $-x \in D$）。

| 类型 | 条件 | 图形特征 |
| --- | --- | --- |
| **偶函数** | $\forall x \in D,\ f(-x) = f(x)$ | 关于 **$y$ 轴**对称 |
| **奇函数** | $\forall x \in D,\ f(-x) = -f(x)$ | 关于**原点**对称 |
| 非奇非偶 | 都不满足 | — |

**几何解释**（教材图 1.9、1.10）：
- 偶函数：点 $A(x, f(x))$ 在图形上 ⟹ 其关于 $y$ 轴的对称点 $A'(-x, f(x))$ 也在图形上
- 奇函数：点 $A(x, f(x))$ 在图形上 ⟹ 其关于原点的对称点 $A''(-x, -f(x))$ 也在图形上

**教材例子**：
- $y = x^2$、$g(x) = x\sin x$ 是**偶函数**
- $y = x^3$ 是**奇函数**
- $y = x^2 + x^3$ 是**非奇非偶函数**

> ⚠️ **判断奇偶性第一步永远是看定义域是否关于原点对称。** 定义域不对称 ⟹ 直接是非奇非偶，不用算。

### （4）函数的周期性

设函数 $f(x)$ 的定义域为 $D$，若 $\exists T > 0$，使得 $\forall x \in D$，有 $x + T \in D$ 且

$$f(x+T) = f(x)$$

恒成立，则称 $f(x)$ 为**周期函数**，$T$ 称为 $f(x)$ 的**一个周期**。

| 要点 | 内容 |
| --- | --- |
| 周期不唯一 | 若 $T$ 是周期，则 $nT$（$n$ 为正整数）也是周期 |
| **最小正周期** | 周期中最小的正数，通常说的"周期"指它 |
| 常见周期 | $y=\sin x$、$y=\cos x$ 以 $2\pi$ 为周期；$y=\tan x$、$y=\cot x$ 以 $\pi$ 为周期 |

> 📌 **不是每个周期函数都有最小正周期。** 教材明确给了反例：**常值函数 $y = 0$（$x \in \mathbb{R}$）**——
> 任何正实数都是它的周期，但不存在最小正周期。这个反例要记住。
