> 一句话：**有界性、单调性、奇偶性、周期性**——描述函数整体行为的四把尺子，全部是后续章节（极限、导数、积分）的判断工具。

## 1. 定义 / 核心结论

| 特性 | 核心条件 | 图形含义 |
| --- | --- | --- |
| **有界性** | $\exists M>0,\ \forall x \in X,\ \lvert f(x) \rvert \leq M$ | 图形被两条水平线夹住 |
| **单调性** | $x_1<x_2 \Rightarrow f(x_1)<f(x_2)$（增）或 $>$（减） | 图形上升 / 下降 |
| **奇偶性** | $f(-x)=f(x)$（偶）；$f(-x)=-f(x)$（奇） | 关于 $y$ 轴对称 / 关于原点对称 |
| **周期性** | $\exists T>0,\ f(x+T)=f(x)$ | 图形按周期重复 |

> 🔑 **四条全部依赖"区间"或"定义域前提"**，脱离前提谈这些性质都是错的。

## 2. 逐条要点

### 有界性

- 有界 $\iff$ 既有上界又有下界
- **关键**：有界性**依赖于所讨论的区间**
  - $f(x)=\sin x$ 在 $(-\infty,+\infty)$ 内有界（$\lvert \sin x \rvert \leq 1$）
  - $f(x)=\dfrac{1}{x}$ 在 $(0,1)$ 内**无上界**（有下界），在 $[1,+\infty)$ 内**有界**

### 单调性

- **必须指明区间**。$y=x^2$ 在 $(-\infty,0)$ 单调减、$(0,+\infty)$ 单调增，但**在 $\mathbb{R}$ 上不单调**
- $y=\dfrac{1}{x^2}$ 同理，分区间讨论

### 奇偶性

- **第一步永远是检查定义域是否关于原点对称**；不对称 ⟹ 直接非奇非偶
- 例：$y=x^2$、$x\sin x$ 偶；$y=x^3$ 奇；$y=x^2+x^3$ **非奇非偶**

#### 🚨 我的错题（2026-09-14）

**习题 1.1 第 5(2) 题**：判断 $y = x\cos x$ 的奇偶性
→ 我判成了**非奇非偶**，正确答案是**奇函数**。

**解法一（代 $f(-x)$，最稳）**：

$$f(-x) = (-x)\cos(-x) = -x\cos x = -f(x) \quad\Longrightarrow\quad \text{奇函数}$$

> 关键一步：$\cos(-x) = \cos x$（$\cos$ 是**偶**函数）

**解法二（乘积法则，最快）**：

$$y = \underbrace{x}_{\text{奇}} \cdot \underbrace{\cos x}_{\text{偶}} = \text{奇}$$

#### ★ 奇偶性的运算规律（记牢能秒杀这类题）

| 组合 | 结果 |
| --- | --- |
| 奇 × 奇 | **偶** |
| 偶 × 偶 | **偶** |
| **奇 × 偶** | **奇** |
| 奇 + 奇 | 奇 |
| 偶 + 偶 | 偶 |
| 奇 + 偶 | **非奇非偶**（一般情况） |

**为什么"奇×偶=奇"**：设 $f$ 奇、$g$ 偶，$F=fg$，则
$F(-x)=f(-x)g(-x)=(-f(x))\cdot g(x)=-F(x)$ ⟹ $F$ 奇。

> 💡 口诀：**"负号只看乘积里有几个奇函数"**——奇数个 ⟹ 奇函数，偶数个（含 0 个）⟹ 偶函数。
> 本题：$x$（奇）× $\cos x$（偶）⟹ 1 个奇 ⟹ **奇**。

> ⚠️ **乘积法则不能替代定义**：遇到**分段函数**或**定义域不对称**时，必须回到 $f(-x)$ 去算。

### 周期性

- 若 $T$ 是周期，则 $nT$（$n$ 为正整数）也是周期
- **最小正周期**：周期中最小的正数，通常说"周期"指它
- 常见：$\sin x,\cos x$ 的周期为 $2\pi$；$\tan x,\cot x$ 的周期为 $\pi$
- ⚠️ **不是每个周期函数都有最小正周期**：**常值函数 $y=0$（$x\in\mathbb{R}$）** 任何正实数都是周期，但没有最小正周期

#### ★ 周期伸缩法则（老师补充，教材未给）

若 $f(x)$ 的周期为 $T$，则 $f(ax+b)$（$a \neq 0$）的周期为

$$T' = \frac{T}{\lvert a \rvert}$$

**为什么**：$x$ 每增加 $\dfrac{T}{\lvert a\rvert}$，括号里 $ax+b$ 就增加 $\pm T$，函数值重复一遍。

**例**：$\sin x$ 周期 $2\pi$ ⟹ $\sin 2x$ 周期 $\dfrac{2\pi}{2} = \pi$；$\sin\!\left(3x+\dfrac{\pi}{4}\right)$ 周期 $\dfrac{2\pi}{3}$。

> ⚠️ **只看 $x$ 的系数，与常数项 $b$ 无关。**
> 经典陷阱：$\sin(\pi x)$ 的周期是 $2$，**不是** $2\pi$。

#### ★ 对数型奇函数的速算（老师补充）

**典型形式**：

$$f(x) = \ln\!\left(x + \sqrt{1+x^2}\right)$$

**判定技巧——共轭因式相乘为 1**：

$$f(-x) + f(x) = \ln\!\left(\sqrt{1+x^2} - x\right) + \ln\!\left(\sqrt{1+x^2} + x\right) = \ln\left[\left(\sqrt{1+x^2}-x\right)\left(\sqrt{1+x^2}+x\right)\right] = \ln 1 = 0$$

$$\Longrightarrow f(-x) = -f(x) \quad\Longrightarrow\quad \textbf{奇函数}$$

**关键恒等式**（平方差）：

$$\left(\sqrt{1+x^2}-x\right)\left(\sqrt{1+x^2}+x\right) = (1+x^2) - x^2 = 1$$

> 💡 同类可记：$f(x)=\ln\dfrac{1-x}{1+x}$ 也是**奇函数**（对数商化差后相加为 0）。
>
> 🔑 **通用套路**：见到 $\ln(\text{根式} \pm x)$ 就想到**乘共轭**，把乘积凑成常数 1。

## 3. 典型例题

**例（教材例 1.1.3）**：判断 $f(x)=\lvert x \rvert$ 与 $g(x)=\sqrt{x^2}$ 是否相同。

- 解：定义域都是 $\mathbb{R}$，且 $\sqrt{x^2}=\lvert x \rvert$，对应法则相同 ⟹ **是同一函数**
- 对比：$f(x)=\frac{x}{x}$ 与 $g(x)=1$，定义域不同（前者 $x\neq0$）⟹ **不是**

**判断奇偶性通用步骤**：
1. 看定义域是否关于原点对称 → 不对称直接结论"非奇非偶"
2. 计算 $f(-x)$，与 $f(x)$、$-f(x)$ 比较

## 4. 易错与坑

- ⚠️ 问"有没有界"不答区间 → 必错
- ⚠️ 说"$y=x^2$ 是单调函数" → 错，必须带区间
- ⚠️ 判断奇偶性跳过"定义域对称"这一步
- ⚠️ 以为周期函数必有最小正周期（反例：常值函数）
- ⚠️ 混淆"关于 $y$ 轴对称"（偶）与"关于原点对称"（奇）
- ⚠️ **求 $f(ax+b)$ 的周期时忘了除以 $\lvert a\rvert$**（把 $\sin(\pi x)$ 的周期当成 $2\pi$）
- ⚠️ 遇到 $\ln(\text{根式}\pm x)$ 不会想到**乘共轭**

## 7. 我的理解

这四条特性不是孤立的知识点，而是**后面所有章节的"预判工具"**：知道单调性就能比较函数值、知道有界性就能用夹逼、知道奇偶性就能简化积分、知道周期性就能只研究一个周期。现在的任务是**记准定义和前提条件**，应用留到后面章节。
