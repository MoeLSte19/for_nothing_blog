| 场景 | 工具 | 产出放哪 |

## ⓪ 直接把笔记或作业照片发给我（当前协作流程）

你可以直接在当前对话上传照片，不必先用 Gemini 识图或整理成 Prompt。流程是：**先在对话里处理内容，再把整理结果写入本库**。

### 高等数学课堂笔记

1. 你拍下手写笔记并上传。我先逐段识读，保留你的记号和例题；例如你写的 `eg:` 按“例题”理解。
2. 我把笔记内容整理成易复习的定义、公式、解题步骤和易错点，不擅自把课堂内容改成另一种讲法。
3. 我对照 `04-资料库/高等数学A（上）/教材-高等数学上册.pdf`，尝试匹配章节、教材页码和现有知识点笔记。
4. 我在回复中说明识读结果、教材位置及不确定之处，再把可确认的内容写入 `01-课程库/高等数学A（上）/` 对应课堂笔记，并把可复用知识点补入 `02-知识库/`。
5. 如果字迹、符号、缩写或教材对应关系无法可靠判断，我会标出具体位置并问你；影响数学结论的疑点未澄清前，不把猜测写成定论。

### 高等数学课本作业

1. 你尽量同一批上传**题目原文和自己的完整作答**；题目在课本上、作答在作业本上时，两部分都拍到。
2. 我先识读题目与作答，再独立核对题目条件、解题步骤、结果；能代回原式或用其他方式检查时，会给出验算。
3. 我逐题说明对错、具体错步、标准解法和教材章节/页码；错误按知识漏洞、方法错误、计算失误区分。没有看到你的作答时，只讲题目，不推断错因。
4. 我在对话中给出批改与需要你确认的识读项，然后把课堂或题目中有复习价值的内容归入对应课程笔记/知识点笔记；错因并入相关知识点，不另造孤立错题集。

### 英语课堂笔记

1. 你上传单词、词根或课堂板书照片。我先按照片整理出单词及老师讲到的词根、派生词和相关知识。
2. 我会区分“照片中明确记下的课堂内容”和“我补充的关联信息”，避免把补充内容误写成老师讲过的。
3. 我在对话里展示整理结果，再归入英语课程笔记或现有词汇知识笔记；如果看不清你自创的缩写或标记，会先问你。

### 每次上传的说明

有就写：课程/章节/题号，或老师特别强调的内容。没有也可以只发照片，我先结合现有课程笔记和教材定位；**无法确定时再向你询问**。照片请尽量拍全题目、条件和解答步骤，避免裁掉页码、图形或公式。

> 识读结果以照片为依据。看不清的字、符号、定义域端点、正负号和上下标会显式标出；不会为了补全笔记而猜。

## ① 打字录入（主流程）

**上课前的准备（一次性）**：把 `06-模板/4-课堂快速捕获模板.md` 打开固定在标签页，上课直接在里面写，下课后另存。
每门课的 `subject`（学科分类）先填好，见 [学科分类](/posts/notes-index)。

**上课中**：

1. `Ctrl+N` 新建笔记，命名 `20260219 第2章 水准测量原理`（**日期 + 章节/主题**）。
2. `Ctrl+P` → 「模板: 插入模板」→ 选 `1-课程笔记模板` 或 `4-课堂快速捕获模板`。
3. 填 frontmatter 的 `course`、`chapter`。
4. 用这套符号速记，别纠结语句通顺：

| 符号 | 含义 |
| --- | --- |
| `??` | 没听懂 / 要查证 |
| `!!` | 老师说这是考点 |
| `→` | 推导 / 所以 |
| `★` | 重点 |
| `例:` | 例题 |
| `@图` | 这里要贴板书照片 |

**上课后 10 分钟内（关键步骤）**：

1. 把 `@图` 的位置补上照片。
2. 把 `??` 的疑问搬进 [作业与考试中心](/posts/notes-index)。
3. 挑出这节课的 1–3 个知识点，在 `02-知识库` 建笔记，从课程笔记里 `双链` 过去。
4. 把这张课程笔记的 `status` 改成 `已整理`。

> **为什么必须当天做第 3 步**：课堂笔记是流水账，知识点才是资产。拖到期末，你面对的是一堆看不懂的缩写。

## ② 拍照录入（你的手写/板书路线）

### 手机上（30 秒）

1. 拍板书/PPT/手写笔记，**尽量正对、光线足、一张只拍一个主题**。
2. 上传到网盘/微信「文件传输助手」/数据线 → 存到电脑的 `00-收集箱`。
3. 手机端也装了 Obsidian 的话：直接在 `00-收集箱` 新建笔记，插入图片。

### 电脑上（5 分钟）

1. **批量改名归档**（可选，但强烈建议）：
   把照片放到 `00-收集箱`，然后在库根目录运行：

   ```powershell
   .\scripts\Import-Photos.ps1 -Topic "水准测量"
   ```

   → 照片自动重命名为 `20260219-水准测量-01.jpg` 并移动到 `05-附件/2026-02/`，屏幕打印出 Markdown 图片链接**并自动复制到剪贴板**，笔记里直接 `Ctrl+V`。

   常用参数：

   | 参数 | 作用 |
   | --- | --- |
   | `-Topic "主题"` | **必填**，出现在文件名里 |
   | `-Date 20260220` | 指定日期，默认今天 |
   | `-Source "某文件夹"` | 改从别的文件夹读照片 |
   | `-Width 400` | 生成的链接带显示宽度，默认 500 |
   | `-Keep` | 只复制不移动，收集箱留底 |

   > 如果提示「禁止运行脚本」，在 PowerShell 里执行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 即可（你的电脑当前已是 RemoteSigned，一般不会遇到）。

2. **取文字**（OCR），按质量从高到低选：

   | 方案 | 适合 | 成本 |
   | --- | --- | --- |
   | **自己照着打一遍** | 手写、公式、中文混排 | 慢，但记忆效果最好 |
   | Windows 自带截图工具 `Win+Shift+S` → 「文本操作」 | 屏幕上的 PPT、PDF 截图 | 免费 |
   | PowerToys 的「文本提取器」(`Win+Shift+T`) | 屏幕上任意位置取字 | 免费，需装 PowerToys |
   | 手机自带「提取文字」（微信/小米/华为相册） | 印刷体中文照片 | 免费，准确率不错 |
   | 多模态大模型（把照片丢给 AI 让它转成 Markdown） | 整页手写笔记、带公式 | 效果最好，能直接出 Markdown + LaTeX |

3. **把文字贴进课程笔记**，并在开头写一句人话总结：

   ```markdown
   > 一句话总结：水准测量利用水平视线读取标尺，通过高差推算未知点高程。
   
   ![[20260219-水准测量-01.jpg|500]]
   ```
   *照片是证据，总结才是复习时真正看的东西。*

## ③ 公式与图表

**通用规则**：行内公式用 `$...$`，独立公式用 `$$...$$`。

```markdown
高差公式：$h_{AB} = a - b$

闭合差：$$\sum h = \sum a - \sum b = 0$$
```

**公式怎么高效录入**：
- 屏幕上的公式 → `Win+Shift+S` 截图 → Mathpix Snip（免费额度每月 10 次，够救急）→ 直接得 LaTeX。
- 手写公式 → 用多模态 AI 拍照转 LaTeX，或自己敲（敲多了其实很快）。
- **最重要的原则：公式旁边一定要写「它是什么意思」**。只有符号没有白话解释的公式，复习时等于没记。

**画图**：
- 简单示意：用 Canvas（右键文件夹 → 新建白板）画方框箭头。
- 控制网、地形草图：装 Excalidraw 插件手绘，或纸笔画完拍照。
- 数据表：**别用图片**，用 Markdown 表格，这样能搜索、能计算。

## ⑤ 每日收尾（2 分钟）

打开 [作业与考试中心](/posts/notes-index) 或今日日报，回答三个问题：

1. 今天哪节课的内容我**说不清楚**？→ 立刻去补知识点笔记。
2. 有没有新作业？→ 建作业笔记，填 `due`。
3. `00-收集箱` 有没有碎片？→ 归位或删除。

> 收集箱超过 20 篇没整理，说明流程太重了。**简化比坚持容易**：宁可每天只记一段总结，也别断掉。

## ⑥ 让 DSH 自动整理（半自动，可选）

前面五节都要你自己动手分类、命名、写 frontmatter。**如果你懒得做这一步，可以让 DSH 代劳。**

### 怎么用（三步）

1. 把原始素材丢进 `00-收集箱`（可以复制 `06-模板/6-素材投放模板.md` 起头），随便什么格式，不用管排版。
   素材开头写清归属最省事：

   ```
   课程: 测绘学概论
   章节: 第2章 水准测量
   日期: 2026-02-19
   ---
   （下面是原始速记/转写文字/摘抄，随便贴）
   ```

2. 打开 PowerShell，`cd` 到库根目录，先看一遍它打算干什么（**不花钱、不调用模型**）：

   ```powershell
   .\scripts\Organize-With-DSH.ps1 -DryRun
   ```

3. 确认没问题后正式跑：

   ```powershell
   .\scripts\Organize-With-DSH.ps1
   ```

   它会对收集箱里每篇素材起一个 DSH 无头会话，代理读完 `.dsh-notes-rules.md` 后，
   自动在 `01-课程库` / `02-知识库` 建好笔记，并打印新建文件清单和它拿不准的疑问。

### 它遵守的硬规则（写在 `.dsh-notes-rules.md` 里）

- **只新建，绝不修改/删除/重命名已有文件**——你的笔记不会被它覆盖。
- 不确定的内容必须标 `> ⚠️ 待核实`，**不许编**（测绘专业的基准面、单位最容易出事）。
- 新建笔记的 `status` 一律是 `待整理`，**掌握度只能你自己判定**。
- 不确定的课程名会照实上报，让你确认。
- 最终回答只有文件清单 + 疑问，不复述内容。

### 什么时候该用它，什么时候别用

| 场景 | 建议 |
| --- | --- |
| 手机拍了一堆板书，AI 已转成文字，懒得分类 | ✅ 用它，这是它最值的场景 |
| 一节课的速记要整理成规范笔记 | ✅ 可以用，省 20 分钟 |
| 公式推导、需要保证绝对正确的专业内容 | ⚠️ 用它打草稿，**但你必须逐条核对** |
| 期末复习想融入已有笔记 | ❌ 别用。它只会建新笔记，不会帮你重写旧的 |
| 只想加一句话到已有笔记 | ❌ 别用。大炮打蚊子，直接改更快 |

### 注意事项

- **每次运行都消耗 API 额度**，批量处理前会问你一次。
- **第一次跑 headless profile 会自动下载依赖**，可能等几分钟，属正常现象。
- 如果提示找不到 `dsh` 命令：把下面这个目录加进 PATH（末尾的 hash 会随 DSH 更新变化）：
  `%APPDATA%\DSH Desktop\host-commands\desktop\generations\<hash>\bin`
- **别手动去改 `.dsh-notes-rules.md` 里的禁止条款**——那是防止代理改坏你笔记的安全底线。

### 为什么不做成 Obsidian 插件？

做到能做，但**不划算**，原因有三：

1. **Obsidian 社区插件不能启动进程、也没有 Node 的完整权限**，想用 DSH 只能反过来：先起一个 DSH web 服务，再在 Obsidian 里嵌个 iframe 显示它。这需要维护服务生命周期、端口、鉴权，而且和 DSH Desktop 自己在跑的 `http://127.0.0.1:43120` 重复。
2. **你已经有更好的答案了**：直接在 DSH Desktop 里开一个会话、把工作目录设成 `E:\DSH\笔记整理`，它就在库里面工作——**你现在这个会话就是**。等于插件要做的交互，桌面版已经免费给你了。
3. 插件一旦装了就得跟 Obsidian 和 DSH 两边版本走，**大一四年里它会坏**。而脚本 + 规则文件是纯文本，坏了你自己就能修。

所以结论：**要交互，用 DSH Desktop 开库目录会话；要自动化，用 `Organize-With-DSH.ps1`。** 两者共用同一套规则文件。

## ⑦ 当前对话协作

你可以在当前对话直接发照片或文字。我会先在回复中识读、整理或批改，再把确认无误的结果写入 `E:\codex\笔记整理` 的对应课程笔记和知识点笔记。你已授权这类学习整理修改现有笔记；遇到无法识别的字迹、符号或个人记号时，我会先问你，不会自行改写成确定结论。

| 你发给我 | 我直接做 |
| --- | --- |
| 一段课堂速记 / 拍下来的文字 | 按双轨结构归入课程笔记和知识点笔记，维护 frontmatter 和 `[[]]` 链接 |
| 高数笔记照片 | 识读整理、尝试匹配教材页码与知识点；需要时批改并更新笔记 |
| 高数作业照片（题目 + 作答） | 逐题核对、解释错步与解法、标教材位置，并把错因归入知识点笔记 |
| 英语单词/词根照片 | 整理老师讲过的词、词根和关联词汇，区分课堂记录与补充信息 |
| 一句「这是我的课表」+ 截图 | 建课程文件夹和总览笔记 |
| 「帮我把 X 这门课的章节骨架搭起来」 | 生成整门课的章节笔记骨架 |

> **照片原件是否另行归档到 `05-附件` 尚待你确认。** 当前协作的确定部分是对话处理后回写整理文字；如果你希望原图也长期保存在库里，告诉我归档偏好即可。

**效率对比**：走对话比跑脚本快得多，而且我能顺便帮你判断结构合不合理、该不该拆笔记。缺点是得你手动发一次。

**建议的工作模式**：

- **每天**：用 ① 打字 / ② 拍照 自己记，保持手感（记忆靠的是这个环节，不是整理）。
- **积压了**：打包丢进收集箱，跑第 ⑥ 节脚本批量清。
- **要调整结构、拆笔记、做复习提纲**：直接在对话里跟我说，这类需要判断的事别交给脚本。
